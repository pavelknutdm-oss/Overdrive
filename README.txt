ОВЕРДРАЙВ — PWA

Содержимое:
- index.html — приложение
- manifest.webmanifest — имя, иконки и параметры установки
- service-worker.js — офлайн-кэширование
- icons/ — иконки приложения

Как установить:
1. Разместите содержимое этой папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте опубликованный адрес в Chrome на Android.
3. Откройте меню браузера и выберите «Установить приложение» или «Добавить на главный экран».

Важно:
PWA нельзя полноценно установить простым открытием HTML-файла с диска. Для manifest и service worker нужен HTTPS (или localhost).
После первого успешного открытия приложение кэшируется и сможет запускаться офлайн.
Суммы сохраняются в локальном хранилище браузера на устройстве.
