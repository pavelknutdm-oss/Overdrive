ОВЕРДРАЙВ — PWA

Все файлы, включая иконки, находятся в корне архива — отдельной папки icons нет.

Как установить:
1. Разместите содержимое этой папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте опубликованный адрес в Chrome на Android.
3. В меню браузера выберите «Установить приложение» или «Добавить на главный экран».

Важно:
Для manifest и service worker нужен HTTPS (или localhost). После первого успешного открытия приложение кэшируется и сможет запускаться офлайн.
Суммы сохраняются в локальном хранилище браузера на устройстве.
